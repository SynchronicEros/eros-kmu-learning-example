# 社團文件|治理要點

本目錄放社團營運文件:會議紀錄、活動企劃、經費表單、交接資料。

## 這個用途的特性

多人協作、幹部年年換、有對外文件(公告、企劃書、成果報告)。
治理重點是**交接存活率**:任何文件都要假設「明年讀它的人不是你」。

## 要點

1. **會議紀錄屬來源層**:內容凍結於開會當下,決議若後來被推翻,
   不改舊紀錄,在新紀錄寫明「取代第 N 次會議之決議」。
2. **成員個資不入 repo**:電話、學號、身分證字號一律不放。
   聯絡資訊放社團自己管控的名冊(不在 git 裡),文件內以職稱稱呼。
3. **對外公告發布前過一次檢核**:至少核對人名職稱、活動資訊、
   圖片授權(參見治理擴增指南階段三)。
4. **建議的子目錄**:`會議紀錄/`、`活動/`(一活動一資料夾)、
   `交接/`。依實際需要開,不必預先開好。

## 常見事故(供借鏡)

- 活動海報用了學長拍的照片,沒問過授權 → 授權不明=不可用。
- 企劃書抄去年的,日期與幹部名單忘了改 → 出稿前檢核就是防這個。
