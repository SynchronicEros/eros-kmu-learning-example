# 研究計畫|治理要點

本目錄放大專生研究計畫文件:申請書、進度紀錄、數據說明、期中期末報告。

## 這個用途的特性

有對外承諾(申請書寫了要做什麼)、有時程壓力、數據有嚴格的
性質界線。治理重點是**承諾與實況分離**、**數據不越界**。

## 要點

1. **申請書屬承諾類來源**:它記錄「當初說要做什麼」,
   不等於「實際做了什麼」。寫進度報告時以實際執行為準,
   與申請書的落差要如實呈現,不粉飾。
2. **數據的性質不得跨用**:
   - 前導/預試數據不得寫成正式結果;
   - 樣本數與適用範圍一律隨數字標明;
   - 「做了幾場、收了幾份」是產出量,不得表述為研究成效。
3. **原始數據不入公開 repo**:涉及受試者的原始資料依 IRB 與
   指導老師規定存放;repo 只放去識別化的分析結果與說明文件。
4. **指導老師的意見屬來源層**:重要指示記成文字(日期+內容),
   不靠記憶。口頭說法有歧義時,回問確認後才寫入文件。
5. **建議的子目錄**:`申請/`、`執行紀錄/`、`數據說明/`、`報告/`。

## 常見事故(供借鏡)

- 期末報告把預試的高滿意度寫成研究發現 → 數據性質標示就是防這個。
- 報告寫「依計畫完成」但實際方法已調整 → 承諾與實況分離,
  落差如實寫,審查者在意的是你知不知道自己改了什麼。
