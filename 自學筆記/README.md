# 自學筆記|治理要點

本目錄放個人學習紀錄:課程筆記、讀書心得、技能練習。

## 這個用途的特性

只有你一個讀者,規範最寬鬆。治理重點只有一個:
**降低寫的門檻,讓紀錄持續發生**。亂而持續的筆記,
勝過完美而中斷的筆記。

## 要點

1. **先寫再整理**:新筆記直接丟進來,累積一陣子再歸類。
   不要為了「還沒想好資料夾結構」而不寫。
2. **標日期與來源**:每篇筆記開頭一行寫日期和材料來源
   (書名、課名、網址)。半年後的你會感謝這一行。
3. **AI 協作的筆記標明性質**:哪些是你自己的理解、
   哪些是 AI 生成的整理,混在一起時你會失去「我到底懂不懂」的判準。
4. **引用他人內容注意份量**:摘要用自己的話寫;
   大段照抄的內容不要放進公開 repo。

## 與另外兩個目錄的關係

這裡練習的習慣(標日期、記來源、區分自己與 AI 的產出),
就是社團文件與研究計畫治理的日常肌肉。從最寬鬆的地方開始練。
