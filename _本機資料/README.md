# 本機資料｜個資原件存放處

本目錄除了這份說明檔，其他檔案都不會進git、不會上傳GitHub（由`.gitignore`排除）。

## 放什麼

社員名冊、受試者名單、含個資的原始問卷、證件影本等，凡是含個人資料的原件都放這裡。

## 規則

1. 其他目錄的文件不抄入個資，以職稱或代號稱呼。
2. 需要分析時，先去識別化，再把結果放到對應目錄。
3. 本目錄沒有雲端備份，請自行另存一份到學校或社團管控的位置。

## 注意

git只能擋住「還沒commit過」的檔。若個資已經commit過，即使事後搬進本目錄，
舊的紀錄仍留在git歷史裡；這時請先停下來，找老師或助教協助處理。
